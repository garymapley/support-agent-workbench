# 演示商城包裹丢失与少件处理政策

> 虚构演示资料。赔付上限与反馈时限为演示参数。

## 一、判定为丢件的三种情形

满足任意一条即可进入丢件流程：

1. 轨迹停滞超过 7 天，且承运商查询无结果
2. 承运商书面确认快件丢失
3. 下单起 30 天内仍未送达，且承运商无法给出合理解释

判定前必须先完成承运商查询并留档。仅凭客户一句"我没收到"就判丢件，是最常见的误判来源。

## 二、三种"没收到"要分开

**（一）在途丢失**
- 订单号与物流单号
- 最后一次轨迹截图
- 客户联系承运商的记录（如有）

**（二）显示签收但客户未收到**
- 订单号与物流单号
- 承运商的签收凭证，含签收人姓名与时间
- 客户本人身份证明
- 小区门卫、公司前台或快递柜的代收记录

这一类不能直接按丢件赔。承运商能拿出本人签收底单的，法律上视为已送达，此时应核查是否为代收、误投或地址填写有误。

**（三）少件或错件**
- 完整的开箱视频，从拆封开始拍，不间断
- 外包装六面照片
- 订单明细与实际收到物品的逐项对照

少件与错件须在**签收后 48 小时内**反馈。超过 48 小时再提出，核实难度大幅上升，但仍应受理并说明核实条件。

## 三、赔付标准

| 情形 | 赔付方式 |
| --- | --- |
| 商家责任（未发货、虚假发货） | 全额退实付金额，运费一并退 |
| 承运商责任且客户已保价 | 按保价金额赔 |
| 承运商责任且未保价 | 按实际损失赔，上限 2000 元 |
| 签收未收到，查实为误投 | 补发或退款，由客户选 |
| 少件 | 优先补发缺失件；无法补发的按件退款 |

关于"未保价只赔运费几倍"：这不是演示商城的规则，也不应作为答复依据。承运商运单上的运费倍数条款属于格式条款，并不是法定赔偿上限，不能直接用来减免赔偿责任。

## 四、时限

- 承运商查询：发起后 48 小时内须有反馈
- 赔付决定：责任确认后 3 个工作日内
- 退款执行：决定后 3 个工作日内

任一环节超时，都要主动告知客户卡在哪一步、下一步什么时候有结果，不能静默等待。

## 五、与破损的边界

丢件是"没收到"，破损是"收到了但坏了"。四类情形分属四条路径：

- 外包装完好、内件损坏 → 质量问题或包装不当
- 外包装破损、内件也受损 → 运输破损
- 整件不见 → 丢件
- 包裹还在但少了配件 → 少件

客户描述含糊时，第一个问题应该是"包裹本身到没到"，而不是直接问损失多少钱。
